ℹ️ Comment ça fonctionne ?
Cette app utilise 3 méthodes combinées pour fonctionner en arrière-plan :

① Alarme système (recommandé)
Quand tu cliques "Répondu", une notification programmée est créée via l'API Notifications. Elle se déclenchera même si l'app est fermée.

② Timestamp sauvegardé
L'heure de fin est sauvée. À la réouverture, l'app vérifie si le timer a expiré.

③ Wake Lock (si dispo)
Empêche l'écran de dormir pendant le timer.

💡 Pour de meilleurs résultats Android : installe l'app via "Ajouter à l'écran d'accueil" dans Chrome.
